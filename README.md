# Diseño de Hornos de Proceso – Método Corto

Aplicación interactiva desarrollada en **Python** y **Streamlit** para el diseño preliminar de un horno de proceso tipo **cabina horizontal con tubos horizontales**, utilizando el **Método Corto** como procedimiento principal de cálculo.

El proyecto permite introducir datos de operación, seleccionar condiciones de diseño, realizar cálculos térmicos y obtener resultados organizados para la revisión técnica preliminar del horno.

---

## Descripción general

Esta aplicación fue desarrollada con fines académicos para facilitar el cálculo preliminar de hornos de proceso mediante una interfaz visual e interactiva.

El programa integra tablas de referencia, correlaciones, interpolaciones y criterios de diseño utilizados en el análisis de hornos, con el objetivo de reducir el trabajo manual y permitir una revisión más clara de los resultados.

---

## Características principales

- Interfaz web desarrollada con Streamlit.
- Diseño preliminar de hornos de proceso.
- Cálculo de carga térmica.
- Evaluación de eficiencia térmica.
- Selección y verificación de tubos.
- Cálculo de sección de radiación.
- Cálculo de sección de convección.
- Estimación de flujo de gases de combustión.
- Evaluación de pérdidas de presión.
- Cálculo de chimenea y tiro.
- Diagnóstico técnico del diseño.
- Visualización de resultados y gráficos.
- Generación de reporte final.
